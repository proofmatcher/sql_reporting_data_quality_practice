# SQL Reporting Data Quality Practice

This repository contains SQL practice for common junior data analyst tasks.

The data is simulated. It is not real voter data and it is not internal Elections BC data.

## What this shows

* Basic reporting queries
* Grouped summaries
* Duplicate checks
* Missing value checks
* Exception reports
* Simple data quality review

## Files

* `data/sample_voter_records.csv`
* `queries/basic_reporting.sql`
* `queries/data_quality_checks.sql`
* `queries/exception_reports.sql`
* `data_dictionary.md`

## Tools

* SQL
* Excel
* Sample CSV data

## Notes

This was created as practice for junior data analyst work. The focus is on readable queries and simple reporting outputs.
